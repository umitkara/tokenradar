# Adım 09 — Frontend bundle ve animasyon ölçümü

**Tarih:** 2026-10-27 · **Sürüm:** 0.0.1 (`step/09-frontend-foundation`) · **Karar:** ADR-031

## Özet

| Ölçüt | Sonuç | Bütçe |
|---|---|---|
| Panel girişi JS (gzip, statik importlar dahil) | **19,7 KB** | ≤ 60 KB ✅ |
| Panel girişi CSS (gzip) | **1,3 KB** | ≤ 15 KB ✅ |
| Mono font (Geist Mono alt kümesi, woff2, ham) | **12,8 KB** | ≤ 25 KB ✅ |
| Galeri girişi (tüm bileşenler, geliştirme derlemesi, gzip) | JS 10,3 KB + ortak çekirdek · CSS 2,4 KB | — (üst sınır göstergesi) |
| Değer değişiminden 2 sn sonra çalışan animasyon | **0** (`document.getAnimations()`) | 0 (ADR-019) ✅ |
| Azaltılmış hareket açıkken çalışan animasyon | **0**; süre token'ları 0 ms, tarama gizli | 0 ✅ |

## Yöntem

- **Bundle:** `pnpm -C app build; node scripts/check-bundle-size.mjs`. Script Vite manifest'inden giriş noktasının statik import ağacını izler; paylaşılan parçalar her sayfaya sayılır. Gzip seviye 9 ile ölçülür. Üretim derlemesinde `gallery.html` bulunursa başarısız olur. CI'da release derlemesinden sonra çalışır.
- **Not:** Panel şu an yer tutucudur (Adım 10). 19,7 KB'nin büyük kısmı Svelte çalışma zamanı, `@fluent/bundle` ve Tauri API'sidir. Galeri tüm bileşenleri içerdiği için panelin Adım 10'daki boyutu için kabaca üst sınır verir: ≈ 30 KB JS.
- **Animasyon:** `pnpm dev` (`TOKENRADAR_FAKE_LIMITS=cycle`, `TOKENRADAR_GALLERY=1`, `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=…`) ile galeri açıldı. DevTools protokolüyle `prefers-reduced-motion: no-preference` taklit edildi, değerler değiştirildi: 150 ms'de 29 animasyon (`stroke-dasharray`, `clip-path` geçişleri, tarama, busy nabzı), 2 sn sonra 0. Ölçüm makinesinde Windows "Animasyon efektleri" kapalıydı; taklit olmadan değişim hiç animasyon başlatmadı.
- **Makine:** Windows 11 (build 26300), WebView2 (Edge Chromium), Node 22.14.
